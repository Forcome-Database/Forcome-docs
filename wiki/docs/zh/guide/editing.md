# 创建与编辑文档

你需要拥有对应空间（或目录/主题）的**编辑权限**才能创建和编辑文档。如无权限，请联系空间管理员开通。

## 创建文档

### 新建页面

1. 在左侧文档树中找到目标位置（目录、主题或父页面）
2. 悬停在目标节点上，点击出现的 **+** 按钮
3. 新页面自动创建并打开编辑器，输入标题即可开始

【占位：点击 + 按钮创建页面的操作截图】

### 创建子页面

在已有页面节点上点击 **+**，新页面成为其子页面。建议层级控制在 3-4 层以内。

### 选择归属位置

创建页面时，注意将文档放入正确的**目录**和**主题**下：

- 方便同事按分类浏览找到
- 方便 AI 检索时缩小范围、提高准确度
- 权限会根据目录/主题自动继承

## 编辑器

打开文档后直接点击正文区域即可编辑，所有修改**实时自动保存**，无需手动操作。

【占位：编辑器全貌截图】

### 常用快捷键

| 操作 | 快捷键 |
|------|--------|
| 加粗 | `Ctrl + B` |
| 斜体 | `Ctrl + I` |
| 下划线 | `Ctrl + U` |
| 插入链接 | `Ctrl + K` |
| 撤销 | `Ctrl + Z` |
| 重做 | `Ctrl + Shift + Z` |
| 标题 1-3 | `Ctrl + Alt + 1/2/3` |

### Markdown 快捷输入

编辑器支持 Markdown 语法自动转换：

| 输入 | 效果 |
|------|------|
| `# ` + 空格 | 一级标题 |
| `## ` + 空格 | 二级标题 |
| `- ` + 空格 | 无序列表 |
| `1. ` + 空格 | 有序列表 |
| `[ ] ` + 空格 | 待办事项 |
| `> ` + 空格 | 引用块 |
| `` ``` `` + 回车 | 代码块 |
| `---` + 回车 | 分割线 |
| `\|列1\|列2\|` + 回车 | 表格 |

### 插入图片

- **粘贴** — `Ctrl + V` 粘贴剪贴板中的截图
- **拖拽** — 将图片文件拖到编辑区域
- **上传** — 点击工具栏图片按钮选择文件

图片自动上传到服务器，无需担心丢失。

::: tip AI 友好提示
纯截图中的文字 AI 无法读取。如果截图中有关键信息（操作步骤、配置参数等），请在截图下方用文字补充说明，这样 AI 问答才能检索到这些内容。
:::

### 插入附件

将文件（PDF、Word、Excel 等）拖拽到编辑区域即可上传为附件，读者可直接下载。

### 插入图表

编辑器支持 Mermaid 图表语法，在代码块中使用 `mermaid` 标记即可渲染流程图、时序图、甘特图等。使用 `mermaid-box` 标记可启用带缩放和全屏功能的容器模式。

## 页面管理

| 操作 | 方法 |
|------|------|
| 移动页面 | 在文档树中拖拽页面节点到新位置（可跨目录/主题） |
| 调整顺序 | 在文档树中上下拖拽 |
| 删除页面 | 右键菜单选择删除，进入回收站，30 天内可恢复 |

::: warning 注意
删除父页面会同时删除其下所有子页面，请谨慎操作。
:::

## 导入文档

支持导入外部文档：

| 格式 | 说明 |
|------|------|
| Markdown (.md) | 直接导入，保留格式 |
| Word (.docx) | 自动转换为富文本 |
| HTML (.html) | 自动解析导入 |
