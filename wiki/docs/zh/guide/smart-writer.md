# 康康写作

康康写作是知识库内置的 AI 写作助手，在编辑文档时帮你起草、润色、翻译和改写内容。

## 打开方式

编辑文档时，点击页面右侧的**康康写作**面板图标。

【占位：康康写作面板入口截图】

## 三种写作模式

康康会根据你打开时的编辑器状态，自动选择写作模式：

| 你的操作 | 触发模式 | 效果 |
|---------|---------|------|
| 选中一段文字后打开 | **选区编辑** | 针对选中内容润色、翻译、改写 |
| 光标放在某个位置，不选中 | **插入写作** | 在光标处插入生成的内容 |
| 没有特定位置 | **全文写作** | 生成完整的新内容 |

### 全文写作

直接输入写作需求，康康为你生成完整内容。

| 场景 | 指令示例 |
|------|----------|
| 起草文档 | "帮我写一份新员工入职的操作手册" |
| 会议纪要 | "根据以下要点生成会议纪要：1. … 2. …" |
| 通知公告 | "帮我写一份系统升级通知" |
| 技术文档 | "帮我写一份 API 接口文档" |

【占位：康康写作面板截图，展示全文写作】

### 选区编辑

先在文档中**选中一段文字**，再打开康康写作。康康会针对选中内容操作：

| 操作 | 指令示例 |
|------|----------|
| 润色 | "帮我润色这段文字，使其更专业" |
| 翻译 | "翻译成英文" |
| 改写 | "用更简洁的语言改写" |
| 扩写 | "详细展开这段内容" |
| 缩写 | "精简为 100 字以内" |

【占位：选中文字后使用康康写作的截图】

### 插入写作

将光标放在文档中某个位置（不选中文字），康康会在该位置插入生成的内容。适合在已有文档中补充段落。

## 上下文感知

康康在写作时会自动读取**当前页面的内容**作为上下文，因此：

- 你不需要重复描述页面已有的背景信息
- 生成的内容会自动与页面风格和主题保持一致
- 如果页面中有表格、列表等结构，康康会参考类似格式

## 应用到页面

生成的内容先显示在面板中供预览，确认后：

1. 点击**应用到页面** — 内容插入或替换到文档中
2. 如果不满意，按 `Ctrl + Z` 撤销，文档恢复到应用前的状态

【占位：应用到页面按钮截图】

## 图片理解

康康支持上传或粘贴图片作为写作参考：

- **粘贴截图** — 输入框中 `Ctrl + V`
- **上传文件** — 点击附件按钮

例如上传一张表格截图，说"把这个表格整理成 Markdown 格式"，康康会识别图片内容并转换。

## 多轮对话

同一个会话中可以不断调整：

```
你：帮我写一份项目周报模板
康康：[生成周报模板]

你：加一个"风险与问题"的章节
康康：[追加风险章节]

你：把格式改成表格形式
康康：[改写为表格格式]
```

## 使用技巧

- **指令越具体效果越好** — "写一份面向新员工的 IT 设备领用指南，包括申请流程和注意事项" 比 "写个指南" 好得多
- **善用选区编辑** — 局部调整比重写整段更高效
- **分步生成** — 复杂文档分章节逐步生成，比一次性生成整篇效果更好
- **结合搜索工具** — 康康可以搜索网页和抓取网址内容作为参考素材
