# 开发计划文档

`docs/plans/` 保存的是开发过程中产出的设计说明、实现计划和阶段性分析文档。

这些文件属于流程文档，不是项目运行时文档，也不是产品说明。之所以保留在原路径，是因为仓库中的其他文档和历史记录仍可能直接引用它们。

建议将此目录中的文件视为以下用途：
- 回溯某次设计或重构的背景与目标
- 理解当时的实现拆分、阶段安排和风险判断
- 查找某个子系统在开发阶段的讨论记录

在依据这些文档继续开发前，应始终以当前代码、测试和实际配置为准进行核对。

完整的流程文档分类与归档范围见 [docs/archive/process-docs-manifest.md](../archive/process-docs-manifest.md)。
