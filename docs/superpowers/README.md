# AI 辅助流程文档

`docs/superpowers/` 保存的是开发过程中由 AI 辅助生成或协作整理的规格文档与执行计划。

这些文件是过程记录，用于保留设计意图、任务拆分和实施顺序，不应直接视为当前代码行为的权威说明。

目录划分如下：
- `specs/`：设计方案、重构提案和规格草案
- `plans/`：基于规格进一步拆出的执行计划和实施步骤

这些路径保持不变，是为了兼容现有引用并保留开发历史上下文。

本次整理纳入范围的流程文档清单见 [docs/archive/process-docs-manifest.md](../archive/process-docs-manifest.md)。
